# Triage labels

| Роль Matt Pocock Skills | Метка в GitHub Issues | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу должен оценить сопровождающий проекта |
| `needs-info` | `needs-info` | Для решения нужны дополнительные сведения |
| `ready-for-agent` | `ready-for-agent` | Задача описана и готова к работе агента |
| `ready-for-human` | `ready-for-human` | Задача требует участия человека |
| `wontfix` | `wontfix` | Задача отклонена |

Когда навык указывает роль, используй соответствующую метку из второго столбца.
